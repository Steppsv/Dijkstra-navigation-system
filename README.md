# Dijkstra Navigation System (C++ / Qt)

A desktop navigation and pathfinding application developed in C++ using Qt.  
The project implements Dijkstra’s shortest path algorithm, graph-based map structures, and interactive route visualization.

## Features

- Dijkstra shortest-path algorithm
- Graph-based city and street modeling
- Interactive Qt GUI
- Route visualization
- Dynamic map loading
- Object-oriented architecture

## Tech Stack

- C++
- Qt Framework
- STL
- Object-Oriented Programming (OOP)
- Graph Algorithms
- Dijkstra Algorithm
- Data Structures

## Concepts Demonstrated

- Graph traversal
- Pathfinding algorithms
- GUI application development
- Modular software architecture
- Route optimization
- Interactive visualization
